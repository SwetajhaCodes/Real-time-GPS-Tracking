# gps_tracking

A Flutter mobile application that tracks the user’s real-time GPS location and displays it on an interactive map .

## Project Overview

This application continuously tracks the user’s GPS position and shows:
- Current latitude & longitude
- Live location on a map
- Travel path using a polyline
